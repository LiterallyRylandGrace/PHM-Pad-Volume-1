# PHM Pad Vol. 1

The PHM Pad Vol. 1 is a macropad designed to compensate for the flaw of many keyboard being the absence of volume-related controls. Inspired by the science-fiction world of Project Hail Mary, it harbours the PHM logo as well as the quote from the movie "Grace Rocky Save Stars". It has six keys as follows, from left to right for the first row and then the second. Previous, Pause/Play, Next, Mute/Unmute, Volume Down, Volume Up.

## Features
- A screwable cover and main body. You don't need much more. Function over form, as they say.
- 6 keys. No more, no less.

## CAD Model
4 Screws and you're good. How innovative am I right? You get a bottom and a top. The design is made to match with my computer case, so it's not guaranteed to work (aesthetically) with yours. To be fair, it is my very first CAD model so I think it doesn't look all to shabby.

## PCB
PCB TIME! I decided to venture a bit away from the tutorial that is the HackPad. My confidence towards anything that I did is almost null, which means you could say that this project is held up by hopes and prayers.

<img src=assets/pcb.png alt="Schematic" width="300"/>

Instead of making a regular matrix with rows and columns I decided to be original and opted for a direct pin configuration matrix.

## Firmware

[QMK](https://qmk.fm/) is used for all of the firmware. I am very lucky they have a tutorial.

6 keys forming the 3 by 2 format. yay.
